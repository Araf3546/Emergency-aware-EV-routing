# P3 Scope Summary

- Build a protocol-driven emergency-aware routing framework for the thesis project.
- Preserve the existing ACO + PSO hybrid as the base and add BCO-style exploration as a third component.
- Use V2V-style vehicle messages to broadcast emergency urgency, route intent, and local traffic state.
- Make emergency handling part of the main routing score instead of a separate patch.
- Target a large-scale simulation setup with 8,000 vehicles, 5–7% emergency vehicles, and a 3,600-second run.
- Log enough data for meaningful before/after comparison between traditional routing and the new E3 Hybrid design.
